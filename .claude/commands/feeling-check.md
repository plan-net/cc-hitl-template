# Feeling Check Command

A simple test command that demonstrates HITL interaction by asking the user how they feel today.

## Usage

```
/feeling-check
```

## What This Does

Invokes the feeling-check agent to:
1. Greet the user
2. Ask how they feel today
3. Provide a thoughtful response based on their answer

This is a minimal example demonstrating the Bansumi HITL pattern.
